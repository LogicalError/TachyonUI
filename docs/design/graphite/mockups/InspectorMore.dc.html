Inspector rules
BannersAbove the object header, full width. Warning: warn at 10%, Discard + Save. Info: info at 8%, a text link.
SearchFilters rows by label. Matches get the selection color; sections without a match collapse and dim to 55%.
AutocompleteThe completion shows inline in text-3; Tab or Enter takes it. The list matches by prefix, matched part in 600.
Mixed valuesCheck box: accent box with a bar. Fields: a muted dash. Dropdowns and text: "Mixed" in text-3. Color: diagonal stripes of the values.
HDR gradientTone-mapped bar; a thin band above marks where values pass 1.0; the max intensity chip opens the exposure.
Curve fields44px plot, plot-bg, grid-major zero line. Hover: strong border and an open button; click opens the curve editor.
LevelsChannel chips, mode and log scale on one row. Clipped ranges shaded. Black, gamma, white handles under the plot; output ramp below.
SlidersEvery ranged number is a slider with a value box (the app shows plain fields today).
